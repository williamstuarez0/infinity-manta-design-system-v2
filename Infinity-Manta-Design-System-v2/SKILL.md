# Infinity Manta Design

Lee `CLAUDE.md` y `DESIGN.md` completos antes de actuar.

Para carruseles, sigue `social/CAROUSELS.md`. Para reels, sigue `social/REELS.md`. En ambos casos aplica `social/MEDIA_POLICY.md`, `social/COPY_GUIDE.md` y `social/EXPORT_CHECKLIST.md`.

Usa los recursos locales de `assets/`; no inventes recursos de marca. La carpeta `assets/references/carousel-approved/` define el piso visual aprobado, pero cada historia debe tener su propio ritmo.
